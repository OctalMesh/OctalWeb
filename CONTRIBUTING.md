<h1 align="center">Contributing to OctalWeb</h1>

Thank you for your interest in **OctalWeb**.

This repository is maintained and developed by the OctalMesh development team. OctalWeb is the
official company website, and all design, layout, and code decisions are managed internally.

External contributions are limited, but feedback is welcome.

## What you *can* do

You are welcome to:

- **Report bugs or issues** (broken links, layout problems, performance issues, accessibility problems)
- **Suggest improvements** (usability, minor UI enhancements)
- **Request clarification** regarding website behavior or content

Please use GitHub Issues and provide:

- Clear description of the problem or suggestion
- Screenshots or examples when applicable
- Information about your environment (browser, device, OS)

## What we *do not* accept

At this time, we do not accept:

- Pull requests that introduce major design changes or new features
- Bulk changes or automated modifications
- Substantial rewrites of content or code

All major updates are coordinated internally to maintain site consistency and integrity.

## Pull Requests

Pull requests may be closed without review unless explicitly requested by the OctalMesh team.
If a contribution is needed, it will be coordinated directly.
